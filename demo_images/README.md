# Demo photos

`bun run seed:demo` (scripts/seed-demo.ts) stores these as the demo user's fit checks. Name each file as below, with any image extension (`.jpg`, `.jpeg`, `.png`, `.webp`, `.heic`). A missing photo is fine, but that fit check has no picture on the wardrobe page and the vision model can only compare against its description.

Photos are ignored by git (only this README is checked in). Use photos you took or have permission to use. One person wearing the same pieces across days looks most real, and the black jeans should be clearly visible: the shopping demo matches a photo of black jeans against them.
